## 🧡 Why MapleStory?
저는 메이플스토리에 11,000시간 이상을 함께한 찐팬입니다. (유니온 9506, Lv.280 블래스터 3캐릭 포함 다수 육성)
단순한 플레이를 넘어, **'메이플스토리는 어떤 방식으로 서버-클라이언트 통신을 할까?'** 를 직접 분석해보며 게임에 대한 애정을 기술적인 공부로 연결해왔습니다.

신규 유저들이 성장의 재미를 쉽게 경험하고, 기존 유저들과 함께 다채로운 경험을 공유할 수 있는 시스템을 만드는 데 기여하고 싶습니다. 
**넥슨 메이플 대학생 게임 커리어 캠프 메토링 3기** 활동은 그 목표를 향한 첫걸음이었습니다.
